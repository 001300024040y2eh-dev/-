# 大富豪 AI対戦

ブラウザでプレイヤー1人対AI3人の大富豪が遊べるゲームです。カードはランダムに4人へ均等に配られ、場札より強いカードを1枚ずつ出します。カードの強さは3から2の順です。

ジョーカーは2枚あり、手札がジョーカーのみのとき以外に出せます。ジョーカーを出して勝つことはできず、場のジョーカーには3だけが勝ちます。AIは出札やパスの前に2〜4秒考えます。

場のカードが出された後、他のプレイヤー全員が出せずパスしたら回が終了します。次の回は、そのカードを最後に出したプレイヤーから始めます。

## 起動

リポジトリのルートで以下を実行します。

```bash
npm run serve
```

ブラウザで `http://localhost:4173` を開いてください。

## テスト

```bash
npm test
```

単一テストファイルを実行する場合:

```bash
node --test test/game.test.js
```
